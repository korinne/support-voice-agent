# Returns and refunds

You can return most gadgets within **30 days of delivery** if they're unused and in the original packaging.

## How to return an item

1. Ask support for a return label. The voice assistant can open the request for you.
2. Pack the item in its original box and drop it off with the carrier.
3. We refund your original payment method within 5 to 10 business days after the return arrives.

Return shipping is free when an item is damaged or defective. For other returns, we deduct $6 from the refund for the label.

## Items we can't take back

- **Instant Tunnel Kits** after activation. Once a tunnel is dug, it can't be undug.
- Personalized or engraved gadgets.
- Gift cards.

## Exchanges

We don't swap items directly. Return the original and place a new order, or ask support about store credit instead.

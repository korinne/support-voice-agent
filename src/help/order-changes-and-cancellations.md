# Order changes and cancellations

## Cancelling an order

You can cancel an order while its status is **Processing**, which usually lasts a few hours after purchase. Once an order has **Shipped**, it can't be cancelled, but you can return it after delivery. See returns and refunds.

## Changing an order

While an order is still processing, support can:

- Change the shipping address.
- Upgrade shipping from Standard to Express.
- Remove an item.

To add an item, place a new order. We can't merge orders after checkout.

## Order statuses

- **Processing:** we're packing your order.
- **Shipped:** the carrier has it, and tracking is active.
- **Delivered:** the carrier marked it delivered.
- **Returned:** we received your return.
